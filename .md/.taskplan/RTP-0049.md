- `npx vitest run test/lint/fronteira-gabarito.test.ts` (em `processamento/`) passa com os 6 casos.

- Arquivo alterado: processamento/test/lint/fronteira-gabarito.test.ts.
- Testes: não executados (regra do usuário; /testar roda).
- Risco: sintaxe `describe(nome, opções, fn)` exige vitest >= 1.x/2.x; se a versão for antiga, mover o timeout para o 3º argumento de cada it.
