# RTP-0093 — Regra DO UPDATE do G-05 voltar a acusar SQL com aspas desbalanceadas ou escapadas por barra

Reserva: Livre
ID no TASK.md: RTP-0093 · Lote: Refatoração Revisão 2026-10-08 · Agente: executor · Chapéu: Backend · Est: 1h · Dep: RTP-0091 · Status no TASK.md: Pendente
Reqs: G-05 · Aceite: em `processamento/test/guardrails/g05-event-store-imutavel.test.ts` a regra `INSERT ... DO UPDATE` volta a acusar quando há número ímpar de aspas antes do `DO UPDATE` (ex.: `'it's'` dentro de string JS), como acusava antes da RTP-0091, e continua aceitando `;` dentro de string balanceada sem atravessar instrução; caso negativo novo; o repositório real continua passando.

## 1. Plano de execução
**Reaproveitamento:** ajustar só a regex `DO UPDATE` em `ESCRITA_PROIBIDA`. Sugestão: alternância ordenada `(?:'[^']*'|"[^"]*"|[^;])*?`, que tenta string balanceada primeiro e recua para aspa solta (é superconjunto do comportamento anterior, sem perder o caso `;` em string).
