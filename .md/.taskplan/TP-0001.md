Reqs: RNF-02, RF-13 · Aceite: `pnpm install`, `pnpm typecheck` e `pnpm test` verdes; `tsconfig` com `strict`, `erasableSyntaxOnly`, ESM; `engines.node` 24; `.gitignore` cobre `dados/`, `.env`, `.wrangler/`, `node_modules`; `.env.example` sem valores; teste abre `node:sqlite` em memória e roda `.ts` sem build

## 1. Plano de execução
1. Criar `package.json` raiz: `"private": true`, `engines.node: ">=24"`, scripts `install`/`typecheck` (`tsc --noEmit -p tsconfig.base.json` chamado por workspace)/`test` (`pnpm -r test`), `packageManager` pnpm.
2. Criar `pnpm-workspace.yaml` com pacotes `processamento` e `web` (`web` ainda não existe — TP-0003 cria; aqui só referenciar o padrão `*` ou listar caminhos, sem quebrar antes do TP-0003 rodar).
3. Criar `tsconfig.base.json`: `strict: true`, `erasableSyntaxOnly: true` (SDD §1/ADR-014), `module`/`moduleResolution: NodeNext` (ESM), `target` recente compatível com Node 24, sem `enum`/*parameter properties*/`namespace` (TASK §1).
4. Criar `processamento/package.json`: `"type": "module"`, script `test` (`vitest run`), devDependency `vitest`; `tsconfig.json` do pacote estendendo o base.
5. Criar `.gitignore` na raiz cobrindo `dados/`, `.env`, `.wrangler/`, `node_modules` (G-01, G-16).
6. Criar `.env.example` vazio de valores (ex.: `OPENAI_API_KEY=`) — nunca com segredo real (G-01).
7. Escrever `processamento/test/ambiente.test.ts`: abre `node:sqlite` `DatabaseSync(':memory:')`, faz um `CREATE TABLE`/`INSERT`/`SELECT` simples, confirma que roda via Vitest sem etapa de build prévia (type stripping nativo).
8. Não criar nada em `dominio/`, `contrato/`, `web/` — fora de escopo desta tarefa (isso é Lote 2+ e TP-0003).
9. Pontos de atenção: `erasableSyntaxOnly` é exigência de G-02/TASK §1 (sem `enum`); `node:sqlite` ainda é *release candidate* no Node 24 — se falhar no Windows/CI, registrar BK e usar plano B `better-sqlite3`/`tsx` sem reestimar (SDD §2 tabela de incertezas, linha 1).

## 2. Plano de teste
- `processamento/test/ambiente.test.ts` (Vitest): (a) abre `node:sqlite` em memória com sucesso; (b) cria tabela, insere linha, lê de volta — confirma round-trip; (c) teste roda `.ts` direto (sem build) — isso é validado pelo próprio Vitest/Node 24 executando o arquivo.
- Comando: `pnpm install && pnpm typecheck && pnpm test` deve terminar verde (0 erros de tipo, suíte com 1+ teste passando).
- Caso de borda: se `node:sqlite` não existir no ambiente de execução (Node < 24 ou flag faltando), o teste deve falhar de forma clara — não é mascarar com try/catch silencioso.

## 3. Plano de validação de segurança
Tarefa de fundação sem superfície de runtime exposta (sem API, sem rede). Mínimo aplicável:
- Checar `.gitignore` cobre `.env` e `dados/` antes do primeiro commit (G-01).
- `.env.example` não deve conter valor real de `OPENAI_API_KEY` ou qualquer chave (G-01).
- Nenhuma dependência nova fora do permitido no SDD §3 nesta etapa (só `vitest` e `typescript`, já previstos) — G-17.
