## Verificação (2026-10-08)

Código já estava implementado (commits anteriores, e o `App`/rotas reais já
evoluíram bem além do placeholder original do TP-0003 — ver nota em
`web/test/app.test.tsx`); esta rodada verificou que o critério de aceite
original ainda é cumprido pelo estado atual do pacote.

- Comando: `pnpm --filter web exec vitest run test/app.test.tsx` →
  **falhou** inicialmente no segundo teste (`vitest-axe`), com
  `Document has more than one banner/main landmark`.
- Causa raiz: `web/test/setup.ts` não registrava `afterEach(cleanup)` do
  Testing Library. Como `web/vite.config.ts` não tem `test.globals: true`,
  o auto-cleanup do `@testing-library/react` (que depende de um `afterEach`
  global já existente) nunca era registrado — cada `render()` dentro do
  mesmo arquivo de teste se acumulava no `document.body`, duplicando
  `<header>`/`<main>` e quebrando o `vitest-axe` em qualquer arquivo de
  teste com mais de um `render()` (caso de `app.test.tsx`, que tem 2
  testes).
- Correção aplicada em `web/test/setup.ts`: import de `cleanup` de
  `@testing-library/react` e `afterEach(() => cleanup())` explícito,
  com comentário explicando a causa.
- Reteste: `pnpm --filter web exec vitest run test/app.test.tsx` →
  **passou** (2/2 testes: renderização da rota padrão e vitest-axe sem
  violações). O "Not implemented: HTMLCanvasElement.prototype.getContext"
  no stderr é aviso benigno do jsdom (contraste de cor do axe-core), não
  falha de teste.
- Comando: `pnpm --filter web run build` → **passou** (`vite build` do
  worker SSR e do client, sem erro).
- `index.html` com `lang="pt-BR"` confirmado por leitura direta do arquivo.
- Esta correção em `web/test/setup.ts` é compartilhada por todos os testes
  de componente do pacote `web` (não só `app.test.tsx`) — risco residual:
  nenhum teste dependia do comportamento anterior (sem cleanup) para
  passar, já que os outros arquivos de teste ou têm 1 `render()` por teste
  ou já chamavam `cleanup()`/`unmount()` manualmente; não identificado
  nenhum teste que quebrasse com o cleanup automático novo.
