# TP-0022 — Adaptador de `rastreio.csv`

Reserva: Livre
ID no TASK.md: TP-0022 · Lote: Lote 4 · Agente: executor · Chapéu: Backend · Est: 2h · Dep: TP-0006 · Status no TASK.md: Pendente
Reqs: RF-02 · Aceite: Eventos `coleta`/`transporte`/`entrega` v1 com `ordem_chegada` = posição da linha; vínculo (`rastreio`, código de rastreio); linha inválida e registro repetido viram achado

## 1. Plano de execução
1. Criar `processamento/src/fontes/rastreio.ts`, adaptador explícito de rastreio (ADR-005, mesma regra de TP-0020/TP-0021: proibido abstração genérica de "fonte").
2. Ler `rastreio.csv` com `csv-parse` (mesma biblioteca de TP-0021). Formato (TASK.md §1): `codigo_evento,codigo_rastreio,pedido_venda,tipo,momento_fato,transportadora`; `tipo` ∈ `coleta`, `transporte`, `entrega`; `codigo_rastreio` = `RS-` + 6 dígitos; ordem das linhas = ordem de chegada.
3. Para cada linha, na posição em que aparece no arquivo:
   - `ordem_chegada` = índice da linha (posição física no CSV, não a ordem canônica de domínio — essa é calculada depois por `dominio/ordenacao.ts`, TP-0007, em outra etapa).
   - Montar `VinculoFonte` `{ fonte: 'rastreio', codigo_externo: codigo_rastreio }`.
   - Montar evento v1 do `tipo` correspondente (`coleta`/`transporte`/`entrega`, `dominio/evento.ts` de TP-0006) com `transportadora` e `codigo_rastreio` (SDD §5: coleta/transporte/entrega v1 têm `transportadora`, `codigo_rastreio`).
   - Linha malformada (campos faltando, `tipo` fora do enum, data inválida) → achado `linha_invalida`, sem lançar erro, continua processando.
   - `codigo_evento` repetido (já visto nesta importação) → achado `registro_repetido`, sem duplicar evento.
4. Devolver `{ vinculos: VinculoFonte[], eventos: Evento[], achados: AchadoQualidade[] }`, puro em memória, sem gravar no SQLite (gravação é TP-0027 + TP-0018).
5. Depende só de TP-0006 (contrato de evento/tipos). Paralelizável com TP-0018, TP-0019, TP-0020, TP-0021 — mas atenção: usa `csv-parse` igual TP-0021; se as duas tarefas rodarem em paralelo e tocarem o mesmo `package.json` do `processamento` (para adicionar a dependência), coordenar para não haver dois `Edit` conflitantes no mesmo arquivo — se `csv-parse` já estiver instalada por TP-0021 primeiro, apenas usar; se este Executor chegar primeiro, instalar e registrar.
6. Atenção: NÃO calcular "fora de ordem" aqui (RN-08, TP-0013) nem transformar `transportadora` em `Transportadora N` (isso é feito na camada de domínio/projeção que lê o evento consolidado, conforme TP-0020 já faz para vendas — aqui o adaptador de rastreio só registra o evento com o dado cru de transportadora vindo do CSV, a tradução/consistência entre fontes é tratada depois).

## 2. Plano de teste
- `processamento/test/fontes/rastreio.test.ts`, com CSV de exemplo fixo.
- Caso: linha válida de cada `tipo` (`coleta`, `transporte`, `entrega`) → vínculo `rastreio` + evento do tipo certo, com `ordem_chegada` igual à posição da linha.
- Caso: 3 linhas em sequência → `ordem_chegada` 0,1,2 (ou 1,2,3, conforme convenção do domínio) refletindo a ordem física, não reordenada.
- Caso: linha malformada (tipo inválido fora do enum, data não ISO) → achado `linha_invalida`, linhas seguintes continuam sendo processadas.
- Caso: `codigo_evento` repetido → achado `registro_repetido`, sem duplicar evento.
- Caso de borda: arquivo vazio (só cabeçalho) → lista vazia de vínculos/eventos/achados, sem erro.
- Rodar: `pnpm --filter processamento test test/fontes/rastreio.test.ts`.

## 3. Plano de validação de segurança
Entrada local (CSV gerado/sintético), sem rede nem usuário externo — risco baixo. Mínimo a verificar:
- Parsing do CSV não lança exceção não tratada que interrompa a importação inteira em linha malformada (robustez exigida pelo RF-02).
- `csv-parse` usado sem opções inseguras; mesma dependência de TP-0021 — confirmar que está listada no SDD §3/GUARDRAILS G-17 antes de instalar duas vezes/gerar conflito de lockfile.
- Nenhum nome de transportadora tratado como definitivo aqui (a tradução para `Transportadora N` acontece depois) — não há vazamento de nome de terceiro na interface final, mas registrar que o dado cru de transportadora transita por este módulo até ser normalizado.
