# TP-0051 — Tokens do Modelo B e fontes auto-hospedadas

Reserva: Livre
ID no TASK.md: TP-0051 · Lote: Lote 10 · Agente: executor · Chapéu: Frontend · Est: 2h · Dep: TP-0003 · Status no TASK.md: Pendente
Reqs: UX-SPEC §3, §5 · Aceite: `tokens.css` com todas as cores, etiquetas, espaçamento e escala do UX-SPEC §3; `@font-face` das 2 famílias em `woff2` (subconjunto latino) com `font-display: swap` e reserva do sistema; licença OFL junto dos arquivos; CSS base (fundo, texto, links sublinhados, foco 3 px com afastamento); teste calcula o contraste WCAG de cada par usado e falha abaixo de 4,5:1 (texto) ou 3:1 (controle e foco)

## 1. Plano de execução
1. Criar `web/src/estilos/tokens.css` com as *custom properties* da UX-SPEC §3: `--cor-fundo` `#0e1217`, `--cor-superficie` `#151b22`, `--cor-lateral` `#11161c`, `--cor-borda` `#263040`, `--cor-divisoria` `#1d2530`, `--cor-borda-controle` `#6b7a89`, `--cor-texto` `#e6edf3`, `--cor-texto-2` `#a3b1bf`, `--cor-destaque` `#2dd4bf`, `--cor-sobre-destaque` `#062420`, `--cor-link` `#7cc4ff`, `--cor-desabilitado` `#6b7a89`; tokens das 6 variantes de `EtiquetaTipo`/estado (texto/fundo/borda, §3 tabela); tokens de espaçamento (4/8/12/16/24/32 px), raio (6 px; 999 px chips/etiquetas), largura do menu lateral (15 rem), largura do conteúdo (72 rem) e escala tipográfica (0,875/1/1,25/1,5/2 rem, base 16 px, altura de linha 1,5).
2. Obter/gerar os `.woff2` de **Manrope** (400/600/700) e **JetBrains Mono** (400/600), subconjunto latino, licença SIL OFL 1.1; salvar em `web/src/estilos/fontes/` junto com o texto da licença OFL (ex. `OFL.txt` por família, ou um único arquivo citando as duas — registrar a decisão). Não baixar de CDN em runtime (G-17, CSP `default-src 'self'`): os arquivos ficam versionados no repositório.
3. Declarar `@font-face` para as duas famílias em `tokens.css` (ou `base.css`, mas manter coerência: fontes podem ficar no mesmo arquivo de tokens ou separado — decisão livre, documentar) com `font-display: swap` e `src: url(...) format('woff2')`; pilha de fallback `system-ui, sans-serif` (Manrope) e `ui-monospace, monospace` (JetBrains Mono) nas variáveis `--fonte-texto`/`--fonte-mono`.
4. Criar `web/src/estilos/base.css`: reset mínimo, `body` com `--cor-fundo`/`--cor-texto`/`--fonte-texto`, links sublinhados com `--cor-link`, `:focus-visible` com contorno 3 px `--cor-destaque` e `outline-offset` 2 px em todo elemento focável, `tabular-nums` para números.
5. Importar `tokens.css` e `base.css` no ponto de entrada do site (`web/src/main.tsx` ou `index.html`) — não criar ainda componentes visuais (isso é TP-0053/TP-0054/TP-0055, fora de escopo).
6. Fora de escopo: `Casca`, navegação, componentes de estado — só tokens, fontes e CSS base global.

## 2. Plano de teste
- `web/test/contraste.test.ts`: função utilitária de contraste WCAG (luminância relativa) aplicada a cada par de tokens efetivamente usado pela UX-SPEC §3 — texto sobre fundo/superfície/lateral (mínimo 4,5:1), `--cor-destaque` como UI sobre fundo/superfície e como contorno de foco (mínimo 3:1), `--cor-borda-controle` sobre fundo/superfície (mínimo 3:1), cada uma das 6 variantes de etiqueta (texto sobre fundo, mínimo 4,5:1).
- Caso de borda: `--cor-desabilitado` é exceção documentada (4,3:1/3,9:1, abaixo de 4,5:1 "de propósito") — o teste não deve reprovar esse par especificamente, mas deve confirmar que ele só seria usado em controle inativo (comentário/nome do teste deixando a exceção explícita, não objeto do cálculo de erro).
- Teste simples confirmando que os `@font-face` referenciam arquivos existentes em `web/src/estilos/fontes/` (ex. leitura do CSS e checagem de que os caminhos resolvem para arquivos no disco).
- Comando: `pnpm --filter web test -- contraste` (ou equivalente do runner do pacote `web`).

## 3. Plano de validação de segurança
Tarefa não toca superfície de segurança de runtime (sem input de usuário, sem rede, sem rota). Mínimo aplicável:
- Nenhuma dependência nova fora do SDD §3/G-17 (fontes são arquivos estáticos, não pacote npm).
- Fontes auto-hospedadas (não CDN externo) é requisito direto de G-13/CSP `default-src 'self'`: confirmar que nenhum `@font-face`/`url()` aponta para origem externa.
- Licença OFL dos arquivos de fonte deve estar presente no repositório (insumo para `AVISO-DE-LICENCA.md` do TP-0067) — não gerar aviso de licença aqui, só garantir que o texto da licença acompanha os arquivos.
- Sem segredos, sem logs.
