# TP-0063 — Tela T3 Indicadores (Must)

Reserva: Livre
ID no TASK.md: TP-0063 · Lote: 13 · Agente: executor · Chapéu: Frontend · Est: 2,5h · Dep: TP-0031, TP-0052, TP-0053, TP-0054, TP-0055 · Status no TASK.md: Pendente
Reqs: RF-08 (M), UX-SPEC T3, §4 · Aceite: Componente `Indicador` que desenha qualquer bloco do contrato (título, fórmula, numerador, denominador, resultado); "sem entregas com data conhecida" quando o resultado é nulo; pedidos sem entrega à parte; divergências por tipo com link para `/?tipo=…`; 4 estados; axe sem violação

## 1. Plano de execução
1. Criar `web/src/componentes/Indicador.tsx`: componente genérico que recebe um `BlocoIndicador` (`chave`, `titulo`, `formula`, `linhas: { rotulos, numerador, denominador, resultado }[]`, `aParte?: { rotulo, valor }`, forma de `EsquemaBlocoIndicador`/`contrato/indicadores.ts`, TP-0031) e desenha: `<h2>{titulo}</h2>`, fórmula em texto secundário, `TabelaDados` (TP-0054) com uma coluna por item de `rotulos` (ex. Transportadora | Mês) + No prazo (numerador) + Entregas (denominador) + % (resultado), e, quando `aParte` existir, uma linha de texto fora da tabela ("{aParte.rotulo} (fora do denominador): {aParte.valor}", espelhando o wireframe "Pedidos sem entrega (fora do denominador): 37"). Quando `resultado === null` numa linha, a célula do % mostra um texto em vez de "0%" ou "—"; o texto exato é passado por prop (`textoSemDados`, com um default genérico) para cobrir tanto "sem entregas com data conhecida" (bloco de entregas no prazo) quanto o texto de outro bloco que futuramente também tenha denominador 0 (Lote 15), sem hardcodar a frase de entregas no componente genérico.
2. Criar `web/src/paginas/Indicadores.tsx`, montada na rota já registrada por TP-0055. Chama `GET /api/v1/indicadores` via `useConsulta`/`clienteApi` (TP-0052) com `z.array(EsquemaBlocoIndicador)`; itera a lista de blocos recebida e renderiza um `Indicador` por item, na ordem em que vêm da API (TP-0039 monta a lista como `[indicadorEntregasNoPrazo, indicadorDivergenciasPorTipo]` — a Must só tem esses 2; o Lote 15/TP-0071 acrescenta itens depois, sem a página precisar filtrar por nome).
3. Bloco "entregas no prazo por transportadora e mês": passar `textoSemDados="sem entregas com data conhecida"` (UX-SPEC §4 linha T3) ao `Indicador` deste bloco especificamente — identificar o bloco certo pela posição/`chave` (confirmar o valor real de `chave` produzido por `dominio/indicadores.ts`/TP-0033 ao integrar; se o literal divergir do suposto, ajustar a constante de comparação na página e registrar no PR, sem travar a tarefa por isso).
4. Bloco "divergências por tipo": cada linha precisa de link para `/?tipo=<literal>` (rota de T1 filtrada, TP-0059/60). Ler o `rotulo`/`rotulos[0]` de cada linha e, se vier como literal de `TipoDivergencia` (`duplicado`, `parcial`, etc.), usar direto no `href`; se vier como rótulo em português, mapear de volta ao literal usando a mesma tabela de `EtiquetaTipo`/`FiltroTipo` (texto → chave) antes de montar o link — confirmar qual das duas formas `indicadorDivergenciasPorTipo` (TP-0033) realmente produz ao integrar (ponto de atenção documentado, não um `PENDENTE` que bloqueie: o código real de TP-0033 resolve a dúvida). Como este bloco precisa de um link por linha que o `Indicador` genérico não tem motivo para conhecer, a página passa um `linkPorLinha?: (rotulo: string) => string` opcional ao `Indicador` só para este bloco (demais blocos não recebem a prop).
5. 4 estados (UX-SPEC §4): carregando ("Carregando indicadores…", `EstadoCarregando`/TP-0053); vazio não se aplica a esta tela como lista geral (cada linha trata seu próprio "sem dados" via `textoSemDados`, não há um "vazio" de tela — a lista de blocos sempre vem com os 2 blocos Must); erro (5xx/rede/timeout) → `EstadoErro` + "Tentar de novo"; sucesso → os blocos.
6. `<title>` "Indicadores — POC_Lab"; foco no `<h1>` ao entrar na rota (padrão de TP-0055).
7. Fora de escopo: indicadores Should ("Tempo médio…", "Valor pago × devido", Lote 15/TP-0071 — não criar essas seções aqui, mesmo que o wireframe T3 já as mostre com a marca `(S)`); qualquer alteração em `Indicador.tsx` para além do que esta tarefa precisa (reaproveitado por TP-0071 depois).

Conferir que o link `/?tipo=` usa só os literais conhecidos de `TipoDivergencia` (nunca interpola texto arbitrário da API direto numa URL sem validar contra a enumeração, mesmo padrão de TP-0059 passo "Parâmetro tipo da URL é validado contra enumeração fixa"). Sem dado pessoal, sem autenticação/autorização aplicável, sem dependência nova.
